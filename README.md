# Rayquaza-Macropad
3x3 rayquaza maropad
Essentially, this is scottokeebs 3x3 macro pad, follow the exact same steps as him, just use the custom case I designed instead when 3d printing:
https://www.youtube.com/watch?v=DfDlfpNA9DU
https://www.printables.com/model/1809668-3x3-rayquaza-keyboard-case

So basically, to clean all of this up, All the deleted files were from me working throughout making this, the file called 'rayquaza' is literally just a rayqauza 3d model, the read me file is... the one your currently reading

The scotto keebs tree is the foundation of this project, the entire thing is based of his 3x3 Macropad. Essentially, what I did was follow his exact steps, everything is the same, except the 'outer case layer' is changed to have a spiralling rayquaza around it, in true sky pillar fashion, I might make a few changes here and here to add more colour and definition to the rayquaza itself, but the dimensions are the exact same, the 3x3 grid that's also a part of the case is not changed, so just use his one. 

The file called 3d case link is the printables website witch I uploaded my model onto, if the download from github isn't working, use this

The file called 'rayquaza 3x3 case cut .stl' is the 3d model of the case, I cut of rayquazas tail so that the model could sit flat without any balancing issues

And that should be everything you need to know for this project, good luck, if you end up making and finishing this project, please send me some pics on pokelegolegends@gmail.com
